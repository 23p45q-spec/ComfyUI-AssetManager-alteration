공통 프롬프트(위 프롬프트 라이브러리/공통 긍정)는 "전체 배경/구도" 설명용으로 남겨두고, 캐릭터마다 다른 특징(머리색, 옷 등)을 주고 싶을 때 여기에 캐릭터별로 나눠 적으세요. 화면 위 미리보기 사각형을 드래그하면 그 캐릭터가 나올 대략적인 위치를 지정할 수 있습니다(안 건드리면 NAI가 자동 배치).

클릭하거나 이미지를 끌어다 놓으세요 (안 넣으면 평소처럼 새로 생성)

강도가 낮을수록 원본과 비슷하게, 높을수록 원본에서 많이 벗어납니다. 해상도는 위에서 고른 값에 맞춰 원본이 자동으로 맞춰집니다(비율이 다르면 크롭될 수 있음).

기존 "🎨 편집" 그림판이 그대로 뜹니다. 다시 그리고 싶은 부분을 아무 색으로나 칠하고 저장하면, 칠하기 전/후를 비교해서 자동으로 흑백 마스크(흰색=다시 그려질 영역)를 만듭니다. 마스크를 안 만들면 이미지 전체가 위 강도값만큼 다시 그려집니다(일반 Img2Img). 위 블러 값을 올리면 다시 그려진 부분과 원본 사이 경계선이 덜 티나게(자연스럽게) 섞입니다 — 0이면 블러 없이 딱 칠한 그대로.

체크포인트/로라 없이 "이 이미지 그림체·분위기랑 비슷하게" 참고시키는 기능. 여러 장 추가 가능(각각 추출강도/적용강도 따로 조절).

Vibe Transfer보다 더 정밀하게 캐릭터/스타일을 참고시키는 기능(V4.5 전용, 최대 16장). 참조마다 종류(캐릭터/스타일/둘 다)와 강도(Strength)·충실도(Fidelity)를 따로 조절.

여기 적으면 전송 직전 프롬프트 맨 끝에 자동으로 "Text: 입력한글자" 형식으로 붙여서 보냄(NAI 공식 문법). 모델별 최대 글자수: V4/V4.5 118자, V5 Curated 374자, V5 Full 750자. 짧은 글자가 잘 안 나오면 아래 "품질 태그 자동 추가"를 꺼보세요.

💡 프롬프트 랜덤화(Prompt Randomizer): 프롬프트 안에 {고양이|강아지|토끼} 처럼 중괄호+｜로 적으면 매 생성마다 그중 하나를 NAI가 알아서 무작위로 골라 씁니다. 이 프로그램이 따로 처리하는 게 아니라 NAI 서버가 직접 해석하는 문법이라, 프롬프트 어디에 적든 그대로 전달되어 자동으로 동작합니다.
💡 프롬프트 조각(Prompt Chunks): NAI 웹사이트 자체에 있는 "@로 저장된 문구 불러오기" 기능인데, 이 프로그램은 이미 "프롬프트 라이브러리"라는 동등한(오히려 더 강력한) 조각 관리 기능이 있어서 별도로 안 만들었습니다.

⚠️ NAI는 로컬 ComfyUI 모델이 아니라 NovelAI 서버 API를 호출하며, 생성할 때마다 Anlas(구독 포인트)가 소모됩니다. 체크포인트/로라/VAE/CLIP, 컨트롤넷/디테일러/모자이크 후처리는 적용되지 않고 무시됩니다(단, 체크포인트가 필요 없는 "일반 업스케일"만은 위 "⬆️ 생성 직후 자동 업스케일" 체크박스로 적용 가능). Img2Img와 인페인팅(마스크로 부분만 다시 그리기)은 위 "Img2Img 원본 이미지"/"인페인팅 마스크" 칸으로 지원되고(NAI 자체 img2img/infill), 캐릭터별 프롬프트는 V4/V4.5 모델에서만 동작합니다(V3 선택 시 무시됨). 해상도/샘플러/스텝/CFG/시드는 위 NAI 전용 설정을 쓰고, 아래 공통 "고급 설정"은 무시됩니다(공통 부정 프롬프트만 그대로 적용). 해상도·샘플러·스케줄러·스텝·CFG·시드와 공통/조각 부정 프롬프트는 그대로 적용됩니다. 토큰은 이 브라우저에만 저장되며 생성 요청 시에만 서버로 함께 전달됩니다.

⚠️ 나노바나나는 로컬 ComfyUI 모델이 아니라 Google 서버 API를 호출합니다. 체크포인트/로라/VAE/CLIP, 그리고 아래 "고급 설정"(해상도/샘플러/스텝/CFG/시드)과 참조이미지/컨트롤넷/Img2Img/인페인팅/디테일러/모자이크 후처리는 전부 적용되지 않고 무시됩니다(추후 지원 예정). 🆕 단, 체크포인트가 필요 없는 "일반 업스케일"만은 위 "⬆️ 생성 직후 자동 업스케일" 체크박스로 적용됩니다. API 키는 이 브라우저에만 저장되며 서버로는 이미지 생성 요청 시에만 함께 전달됩니다.

⚠️ GPT(OpenAI)도 로컬 ComfyUI 모델이 아니라 OpenAI 서버 API(gpt-image-1)를 호출합니다. 체크포인트/로라/VAE/CLIP, 그리고 아래 "고급 설정"(해상도/샘플러/스텝/CFG/시드)과 참조이미지/컨트롤넷/Img2Img/인페인팅/디테일러/모자이크 후처리는 전부 적용되지 않고 무시됩니다(추후 지원 예정). 🆕 단, 체크포인트가 필요 없는 "일반 업스케일"만은 위 "⬆️ 생성 직후 자동 업스케일" 체크박스로 적용됩니다. API 키는 이 브라우저에만 저장되며 서버로는 이미지 생성 요청 시에만 함께 전달됩니다.

체크포인트 없이 바로 돌아가는 빠른 업스케일(Pillow Lanczos)입니다. 원본은 그대로 두고 같은 폴더의 upscaled 하위 폴더에 확대본을 추가로 저장합니다. 🆕 모델 기반 업스케일·디테일러·모자이크를 쓰고 싶으면, 이것과는 별개로 위에서 체크포인트를 고른 뒤 "고급 설정"의 업스케일링/디테일러/검열 체크박스를 켜세요 — 생성 완료 후 자동으로 큐에 추가되고, 끝나면 히스토리 패널에 따로 나타납니다(시간이 좀 걸립니다).

⚠️ 아래 체크포인트/VAE/CLIP/로라는 나노바나나·GPT·NAI 생성 자체엔 쓰이지 않습니다. "고급 설정"의 업스케일링/디테일러/검열을 켰을 때만, 생성 완료 후 이 체크포인트로 후처리를 돌리는 데 쓰입니다. 후처리를 안 쓸 거면 비워둬도 됩니다.
